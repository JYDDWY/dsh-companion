# dsh-companion · DSH 陪玩插件

在 Windows 上玩游戏、看视频或写代码时，让 DSH 定时观察屏幕，结合你设置的人格说几句，并通过本机语音朗读。面板支持暂停、手动“看一眼”、文字聊天、节奏设置、世界书和桌面字幕。

当前版本：**1.9.6-test4（测试版）**。正在进行新电脑安装与使用验证，欢迎通过 [Issues](https://github.com/JYDDWY/dsh-companion/issues) 反馈问题。

## 使用条件

- Windows 10/11，安装并启动过 DSH 0.2.x。
- 在 DSH 中配置可用模型；识图模型需要支持图片输入，可在插件设置里单独选择。
- 基础插件不要求另装 Python、显卡或 RVC：截图可使用 PowerShell 兜底，朗读可使用 Windows 系统语音。
- RVC 语音为可选增强功能。可直接从陪玩设置中一键安装 CPU 运行环境；使用国内 npm、PyPI 和 PyTorch 镜像，模型需自行下载。

## 安装

在 DSH「插件 → 添加插件」中输入：

```text
@jyddwy/dsh-companion@1.9.6-test4
```

安装源可选择「中国大陆镜像源」。该镜像需要先同步本包的对应版本；安装成功后按 DSH 提示刷新或重启，打开右侧「陪玩」并点「看一眼」验证。

命令行等价方式：

```powershell
dsh plugin --profile desktop add @jyddwy/dsh-companion@1.9.6-test4
```

包名中的 `@jyddwy/` 用于区分同名项目；面板和用户数据目录仍使用「陪玩」和 `dsh-companion`。完整说明见 [INSTALL.md](INSTALL.md)。

## 更新版本

插件不能自我更新，更新入口来自 DSH 插件管理：

- 在 DSH「插件 → 添加插件」里重新输入精确版本，例如 `@jyddwy/dsh-companion@1.9.6-test4`，按提示覆盖安装后刷新/重启；
- 装了带「检查更新」的插件管理器 UI（如 `@linxin666/dsh-web-all`）时，插件详情页会多出「更新」区块；
  DSH 自带/市场详情页不一定提供升级操作，需要手动输入版本；
- 命令行等价：`dsh plugin --profile desktop add @jyddwy/dsh-companion@1.9.6-test4`。
- **发布新版本时，维护者需要同步把 npm `latest` 指向新版本**，否则「检查更新」会按旧的 `latest` 判断：
  `npm dist-tag add @jyddwy/dsh-companion@<新版本> latest`

## 可选：RVC 语音增强

先确认基础插件能正常使用，再打开「陪玩 → 设置 → 声音」，点击 **下载并安装语音增强（CPU）**。

- 安装器从国内源获取独立 Python、语音服务、RVC 推理代码和 CPU 依赖，无需访问 GitHub，无需手动安装 Python 或使用命令行。
- 需下载数百 MB，并预留约 3 GB 空间。面板显示安装状态和日志，支持取消、失败重试；退出 DSH 会取消安装。
- **不包含任何角色声线、HuBERT 或 RMVPE 模型权重，也不会自动下载模型。** 环境装好后点击「打开模型目录」，按 [模型指南](docs/RVC-声线下载指南.md) 放置文件。
- 增强环境和模型存放于 DSH 用户数据目录的 `dsh-companion/voice/`，更新主插件会保留它们。主插件卸载后也保留这些用户数据。
- 此入口先提供 CPU 版，实际推理速度取决于硬件；已有手动配置的语音环境仍可使用。

## 日常使用

- 默认开启自动观察，观察间隔为 45 秒；设置里可调整间隔、连拍数量、画面大小和每小时观察上限。
- 前台场景可识别为游戏、看视频、写代码，也可以调整场景开关和游戏白名单。
- “暂停”停止自动观察；“看一眼”是用户主动发起的一轮观察，可在暂停状态下使用。
- 设置里的声线栏始终是下拉框：一键安装环境只列出**实际已下载**的声线模型（服务内置声线表里未下载的不会显示）；自定义外部语音服务仍用它返回的列表。
- 打开设置、语音增强安装完成、重启语音后会自动刷新声线；服务未启动或没有模型时会给出对应提示和「刷新声线」按钮，不需要刷新整个 DSH。
- 当前保存的声线暂时不可用（未下载/服务未启动）时会明确标注，但配置会保留，不会静默改成第一个声线。
- 使用 Windows 系统语音时会明确提示：RVC 声线/音调设置不生效。
- 设置里可切换语音后端、关闭朗读、调整人格与内置提示词。
- 可在面板里打字聊天，或“开新对话”归档历史；游戏世界书支持生成和编辑。
- 没有本地语音增强服务时，语音后端保持“自动”或选择“系统语音”。

## 截图、数据与模型调用

**截图会发送给 DSH 中配置的模型服务商，并非只在本机进行识图。** 使用前请留意屏幕上可能被截入的内容，以及所选模型服务商的数据政策。

- 截图、配置、聊天历史、世界书和日志保存在 `%USERPROFILE%\.dsh\dsh-companion\`；设置了 `DSH_HOME` 时使用对应目录。
- 默认会自动观察识别出的陪伴场景；不希望自动观察时，请在面板中暂停或关闭总开关。
- 一轮观察通常包含识图和生成台词两次模型调用，重写台词可能增加调用。模型用量按你自己的服务商账户计算。
- 自动世界书调研会调用 DSH 的网页搜索与模型能力，查询游戏资料。
- 截图缓存可设置保留轮数、容量和时长，并可手动清理。

## 已知问题

当前测试版还存在以下两种操作交错问题：

1. 手动清理缓存时恰好启动新截图，可能导致当轮截图失败。测试期间可先暂停观察，等当前工作结束，再清理缓存。
2. 自动世界书调研期间先修改观察间隔、再暂停，旧调研可能继续完成。需要暂停时可先直接暂停，待调研结束后再修改间隔。

独占全屏、HDR 或受保护画面的捕获效果依赖具体程序与系统环境；遇到异常可尝试无边框窗口。当前版本尚未完成独立新电脑上的完整安装验收。

反馈时请提供：插件版本、DSH 版本、操作步骤、报错文字。日志在数据目录的 `companion.log` 和 `services/` 中；分享日志、截图前请检查其中的私人信息。

## 开发与验证

插件代码无需构建。`index.js` 为宿主入口，`client.js` 为面板，宿主实现位于 `src/host/`，截图服务位于 `services/`，Windows 助手位于 `win/`。

本地验证可使用 Node.js 22 或更新版本：

```powershell
node --test test/unit.test.mjs
node test/regressions.mjs pause
node test/fallback-regression.mjs
```

`regressions.mjs` 还包含截图缓存、世界书、模型用量和系统语音等隔离场景。当前 94 项单元断言和 18 个隔离回归场景通过；这不代替真实设备验收。
