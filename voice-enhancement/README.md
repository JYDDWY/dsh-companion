# 可选语音服务源码

这里保存项目的语音服务、情绪参数和依赖清单。基础插件不会自动启动此目录中的代码。

完整运行环境由插件设置页「下载并安装语音增强」一键安装（独立 runtime 包），无需手动找 ZIP；模型需要按 [下载指南](../docs/RVC-声线下载指南.md) 自行下载。

RVC 推理代码及第三方依赖随独立 runtime 包提供并保留各自许可证；此源码目录不包含它们，也没有声线权重。

2026-10-23 起情绪语调改为温和档：pitch/语速/停顿都按 march7 实测收敛，分句拼接处加了淡入淡出和低电平底噪，减少「换人感」和数字静音突兀。实测报告见项目开发目录的 `artifacts/emotion-experiment-march7.md`，不随 npm 包发布。
